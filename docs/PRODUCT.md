# Product

Thinking Graph is a Hebrew, RTL thinking workspace: capture thoughts, organize ideas
and connections, and return to their sources. Users may start from Chat or directly
from My Map; a note is also a persistent capture source.

Stable decisions:
- Ideas may appear in multiple workspaces and messages. Authorship records provenance,
  not exclusive ownership. Preserve source links and edit history.
- Keep user ideas distinct from proposed interpretations. Local-model extraction is
  reviewed before adding results to the graph; it is not proof of understanding/truth.
- Desktop uses Chat / Map / Drawing panels. Mobile shows Chat / Notes / Map one at a time.
- Notes and messages use the same server data on both layouts. Drawing and visual
  preferences currently remain browser-local.
- Prioritize the usable local product and explicit user control. No implicit publication.

The dated design-delta documents are proposals/historical context, not an active backlog.
See PARKED before treating their unimplemented sections as requirements.
